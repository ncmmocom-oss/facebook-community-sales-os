1. Import JSON

Chọn file posts*.json, comments*.json hoặc posts JSON có comment lồng bên trong. Hệ thống tự đếm bản ghi quét, lọc trùng, lấy Media CDN và đưa dữ liệu mới lên đầu bảng.


Nếu đã chọn file JSON, phải bấm IMPORT JSON. Nút Đồng bộ Sheet không đọc file đã chọn.

3. Social AIO Worker Pool — 3 tài khoản

Mỗi Worker = 1 tài khoản/browser profile Social AIO đang mở Automation → APIs → Connect. Copy CLIENT_ID của từng tài khoản và dán vào đúng Worker. Hệ thống tự chia Group cho tối đa 3 Worker chạy song song.

Setup một lần: mở 3 browser/profile → Connect APIs → copy 3 CLIENT_ID → dán W1/W2/W3 → LƯU & TEST 3 WORKER. CLIENT_ID chỉ lưu trong Document Properties, không ghi vào Sheet/GitHub.
