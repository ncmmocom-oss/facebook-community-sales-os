Social AIO → Community Sales OS

1. Import JSON

Chọn file posts*.json, comments*.json hoặc posts JSON có comment lồng bên trong. Hệ thống tự đếm bản ghi quét, lọc trùng, lấy Media CDN và đưa dữ liệu mới lên đầu bảng.


Nếu đã chọn file JSON, phải bấm IMPORT JSON. Nút Đồng bộ Sheet không đọc file đã chọn.

2. AI phân tích cơ hội

Google Sheets không cần API key riêng: Apps Script đang dùng OAuth của chính file Sheet. Key này chỉ dùng nếu chọn Gemini để phân tích.
Đang đọc cấu hình...
Chưa có tiến trình AI.

3. API Bridge POC — quét trực tiếp, không tải JSON

Mở Social AIO → Automation → APIs → Connect, giữ tab APIs đang kết nối, sau đó dán CLIENT_ID vào đây. Google Sheet sẽ gọi relay chính thức api.fbaio.org để chạy API bằng phiên Facebook đang đăng nhập trong browser.

Đang đọc cấu hình Bridge...
POC hiện chỉ gọi page đầu để nghiệm thu đường truyền, schema post/comment và tốc độ. Sau khi PASS mới bật pagination + scheduler cho 15–30 Group/Profile. CLIENT_ID chỉ lưu trong Document Properties, không ghi vào ô Sheet/GitHub.

4. QUÉT NHÓM API — điều khiển trực tiếp từ sheet QUÉT NHÓM

Trong sheet QUÉT NHÓM, cột Chọn API dùng để chọn nhiều Group. Muốn quét một Group, chỉ cần click vào bất kỳ ô nào trên dòng đó rồi bấm QUÉT DÒNG ĐANG CHỌN. Cách này không cần Apps Script onEdit trigger và không cần thêm quyền ScriptApp.

Đang đọc danh sách Group...
Chưa chọn Group.
POC dùng page đầu. Batch tự dừng trước giới hạn thời gian Apps Script; các Group chưa chạy vẫn giữ dấu chọn để bấm tiếp. Lệnh DỪNG có hiệu lực sau API call/page đang chạy. Control Center là modeless nên anh có thể chọn dòng/tick Group trong Sheet trong khi cửa sổ này vẫn mở.
